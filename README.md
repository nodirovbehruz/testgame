# Train Survivor Offline

A premium 2D survival game designed for offline play (perfect for train travels). Built as a Progressive Web App (PWA) with vanilla JavaScript and Canvas API.

## Features
- **Offline First**: Works without internet once installed.
- **Dynamic Difficulty**: 40 waves of increasing intensity.
- **Upgrade System**: Choose from 14 different upgrades including damage, speed, magnet, orbital knives, and more.
- **Boss Fights**: Encounter powerful bosses every 5 waves.
- **PWA Ready**: Can be installed on mobile and desktop as a native app.
- **Touch & Keyboard Support**: Play with a virtual joystick on mobile or WASD on desktop.

## How to Play
- **Objective**: Survive 40 waves of enemies and defeat the final boss.
- **Controls**:
  - **Mobile**: Use the touch joystick on the left to move. Double-tap to dash (if unlocked).
  - **Desktop**: Use WASD or Arrow Keys to move. Escape to pause.
- **Auto-Shoot**: The character automatically targets the nearest enemy.
- **Upgrades**: Collect XP shards dropped by enemies to level up and choose upgrades.

## Technical Details
- **Engine**: Pure Vanilla JS / HTML5 Canvas.
- **Styling**: Modern CSS with glassmorphism and radial gradients.
- **Asset-less**: All graphics are procedurally generated via Canvas API for minimum file size and maximum performance.
